# Note Service With ProtoBuff

`#study_project_CU` `#go` `#java`

Реализация gRPC-сервера на Go и gRPC-клиента на Java для сохранения и управления заметками. 

## Содержание
- [Технические особенности](#технические-особенности)
- [Запуск прода](#запуск-прода)

## Технические особенности
- Используется `in-memory` хранение заметок без использования БД
- Разделение по ролям отсутствует, заметками может управлять любой клиент (предполагается, что заметки относятся к единственному клиенту и нет привязки к пользователям)
- Для gRPC реализованы только `unary` запросы
- Во время поднятия сервера запускаются интеграционные тесты (не работают при отключенном сервере)

## Запуск прода
Перед запуском сервера необходимо сгенерировать proto файлы. Заранее проверьте, что у вас установлен `protoc`. Делается это с помощью команды:
```bash
protoc --version
```
Команда для генерации файлов:
```bash
go generate ./...
``` 

Затем нужно собрать программу:
```bash
go build -o '<your-file-name>' ./cmd/server/main.go
```
Вместо `<your-name>` вы можете указать любое название для исполняемого файла. Например, `server`, если у вас unix-система или `server.exe`, если windows.

И наконец, во время запуска программы необходимо передать адрес прослушивания:
```bash
./<your-name> '<your-port>'
```

Пример:
```bash
./server :8080
```
